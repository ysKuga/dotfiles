# 設定関連

> スクリプト化済み: dotfiles の `README.md` の手順（手動 clone → mise インストール → `mise run setup`）で実施される。以下は経緯のメモ。

以下の対応を行う。また都度項目は追加など行う。

## dotfiles 適用

`.gitconfig` と `.bashrc` はこれで設置される。何度実行しても問題ない。

```sh
cd ~/work/ysKuga/dotfiles
./install.sh
exec bash  # 反映
```

## .gitconfig 設置

- repo の `git/config` を `~/.config/git/config` へ symlink（user, core.editor=vim, init.defaultBranch=main）
- `~/.gitconfig` は `git/gitconfig.example` をコピーして作成（未作成・空のときのみ）。`git config --global` や gh の credential helper の書込先はこちらになり repo は汚れない
- credential helper は `gh auth setup-git` だと gh のバージョン付き絶対パスが書かれ `mise upgrade` で壊れるため、`mise run gh-auth` で mise の shim を指定する

## gh コマンドインストール

sudo が必要なため手動で実行。

```sh
./setup/gh.sh
gh auth login
gh auth setup-git
```

## git のコミットメッセージ編集時など nano でなく vi が起動するようにしたい

<https://qiita.com/tacker530i/items/77d195eeee6bb2bfa51b>

- git: `git/config` の `core.editor = vim` で対応済み（`./install.sh` で適用）
  - 確認: `git var GIT_EDITOR` → `vim`
- その他: `bash/bashrc.d/editor.sh` の `EDITOR` / `VISUAL` = vim で対応（sudo 不要）
  - `crontab -e` など `sensible-editor` 経由、`sudoedit` は環境変数を参照するため vim になる
  - `editor` コマンド直接実行と `sudo visudo` のみ nano のまま（`/usr/bin/editor` の alternatives を参照）
    - visudo は `sudo EDITOR=vim visudo` で回避

## .bashrc 設置

<https://gist.github.com/ysKuga/7263ad4944c27e5dcc60118a47686abc>

- `~/.bashrc` は Ubuntu 標準 (`/etc/skel/.bashrc`) のまま。末尾に `~/.bashrc.d/*.sh` の読込ブロックのみ追記
- repo の `bash/bashrc.d/*.sh` を `~/.bashrc.d/` へ1ファイルずつ symlink
  - `editor.sh` — EDITOR/VISUAL=vim
  - `prompt.sh` — 改行して `$`、git ブランチ表示
- マシン固有の設定は `~/.bashrc.d/` に直接 `.sh` を置く（repo 管理外）
- ツールのインストーラが `~/.bashrc` に自動追記するものはそのままにしておく
