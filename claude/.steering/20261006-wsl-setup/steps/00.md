# Ubuntu インストール直後

> スクリプト化済み: dotfiles の `README.md` の手順（手動 clone → mise インストール → `mise run setup`）で実施される。以下は経緯のメモ。

ツールの設定などをほとんどやっていないが作業可能な最低限の状態に持っていく。

## Claude Code インストール

> 現在は mise（`mise/global.toml` の `claude`）で管理している。curl で入れた `~/.local/share/claude` は不要（`rm -rf ~/.local/share/claude` で削除）。

<https://code.claude.com/docs/ja/overview>

```sh
curl -fsSL https://claude.ai/install.sh | bash
```

## 設定用リポジトリ clone

gh コマンドのインストールなど検討するがいったん以下を clone

```sh
git clone https://github.com/ysKuga/dotfiles.git
git clone https://github.com/ysKuga/settings.git
```

## make コマンド

> 不要: `Makefile` は `make help`（`mise tasks` の表示）のみで、セットアップは `mise run setup` で行う。

```sh
sudo apt update
sudo apt install make
```

## VSCode インストールは「不要」

以下コマンドを実行することで自動でダウンロード、インストールされるので特別な作業は不要

```sh
code dotfiles
```
