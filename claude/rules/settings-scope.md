# Settings のスコープ分離

Claude Code の設定は「汎用性」の観点で3層に分離する。

## dotfiles: `claude/settings.json`(コミット対象)

どの端末・どのリポジトリでも共通して有効な設定のみを記述する。

- 絶対パス(`/home/yskuga/...` など特定ユーザー・特定マシンのパス)を直書きしない。`$HOME` 経由の参照(hooks の command 内など)は可
- 特定リポジトリでしか使わないコマンドの許可(`Bash(... 特定ファイルパス ...)` 等)を含めない
- プラグイン設定・テーマ・言語設定など、ユーザーとして常に使いたい設定はここに書く

## dotfiles: `claude/settings.local.json`(gitignore 対象、`~/.config/git/ignore` で全体除外済み)

その端末固有の設定を書く。

- ホームディレクトリの絶対パスを含む permission ルール
- その端末にしか無いツール・パス前提の設定

## 各リポジトリ配下: `.claude/settings.json`(コミット対象)

そのリポジトリでのみ意味を持つ設定を書く。

- そのリポジトリ固有のテストコマンド・スクリプト実行の許可
- チームで共有したい hooks・permission

判断に迷った場合、「他のリポジトリ・他の端末に持っていっても意味が通るか」を基準にする。通らなければ local か各リポジトリ配下の設定に落とす。
